# データモデル

スプレッドシートのシート構造と、シート間の関連を定義します。

## シート一覧

| シート名 | 役割 |
|---|---|
| README_使い方 | 利用者向けガイド (人間が読む) |
| 01_クライアントマスタ | 6社のクライアント情報 |
| 02_品目テンプレート | 各社の請求項目雛形 |
| 03_請求一覧 | 月次請求の縦型台帳 (1行=1請求) |
| 03b_請求明細 | 各請求の品目行 (ステップ2で追加) |
| 99_freee設定 | 共通設定値 |

## 03_請求一覧

| 列名 | 型 | 設定タイミング | 説明 |
|---|---|---|---|
| 請求ID | string | 自動生成 | 例: `INV-202604-001` |
| 対象月 | string | 自動 | 例: `2026-04` (月初トリガーで生成) |
| クライアントID | string | 自動 | マスタへの外部キー |
| 企業名 (自動) | formula | 自動 | VLOOKUPで表示 |
| 案件オーナー (自動) | formula | 自動 | VLOOKUPで表示 |
| 送付方法 (自動) | formula | 自動 | |
| 送付先 (自動) | formula | 自動 | |
| 件名 | formula | 自動 | テンプレ + 年月で自動生成 |
| 税抜金額 | number | オーナー入力 | |
| 消費税 | formula | 自動計算 | 税抜 × 10% を四捨五入 |
| 税込金額 | formula | 自動計算 | 税抜 + 消費税 |
| ステータス | enum | システム管理 | 後述の状態遷移参照 |
| 入力者 | string | 自動 | オーナーのメールアドレス |
| 入力日時 | datetime | 自動 | |
| 承認者 | string | 自動 | みくのメールアドレス |
| 承認日時 | datetime | 自動 | |
| 送付完了日時 | datetime | 自動 | メール送信成功時 |
| freee請求書ID | number | 自動 | 発行時にfreeeから取得 |
| freee deal_id | number | 自動 | 発行時にfreeeから取得 |
| PDF Driveリンク | string | 自動 | freee public URL |
| メモ | string | 任意 | 自由記述。差戻理由などを追記 |

### ステータスの状態遷移

```
未入力 → 入力済 → 承認済 → 発行済 → 送付済 → 入金済
                ↓                              ↓
              差戻 → 入力済                未消込警告 → 入金済 (手動消込後)
```

| ステータス | 意味 | 次のアクション |
|---|---|---|
| 未入力 | 月初に自動作成された初期状態 | オーナーが入力フォームから入力 |
| 入力済 | オーナー入力完了 | みくが承認 |
| 差戻 | みくが差し戻し | オーナーが再入力 |
| 承認済 | みく承認完了 | 一括発行ボタンで処理 |
| 発行済 | freee請求書作成完了・PDF保存完了 | 自動でメール送付実行 |
| 送付済 | メール送付完了 | freee自動マッチングで消込待ち |
| 入金済 | 売掛金消込完了 | (終端状態) |
| 未消込警告 | 期日経過後も未消込 | みくが手動で消込 |

## シート間の関係図

```
01_クライアントマスタ (6社)
    ↓ クライアントID で参照
02_品目テンプレート (固定・変動雛形)
    ↓ クライアントID で参照
03_請求一覧 (月次の請求台帳)
    ↓ 請求ID で参照
03b_請求明細 (品目行)
```

## データ整合性ルール

Claude Code はこれらをチェックする関数を実装すること:

1. **クライアントID の一意性**: `01_クライアントマスタ` で重複してはならない
2. **freee取引先ID の一意性**: 同じ partner_id を2つのクライアントに紐付けてはならない
3. **稼働中クライアントは必ず Toアドレスを持つ**: 送付方法が `メール` の場合
4. **請求IDの一意性**: `03_請求一覧` で重複してはならない
5. **同一月・同一クライアントの請求は1件のみ**: 月初の自動作成時に重複チェック

これらをチェックする関数 `validateData()` を `Main.gs` に実装し、メニューから手動実行できるようにする。
